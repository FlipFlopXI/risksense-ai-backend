# RiskSense AI app walkthrough

`risksense_ai_app_walkthrough.mp4` is a 49-second portrait recording of the current Flutter build running in an Android emulator. Visible touches show dashboard navigation, scrolling, Nutrition tabs, Fitness body metrics, and Mindfulness. It is silent.

The app was launched with `medguide/tool/interaction_demo.dart`. The account name and clinical values shown on the dashboard are illustrative, local demo data. No real patient account or database record was used in the recording.

`risksense_ai_app_walkthrough_poster.png` and `scripts/create_app_walkthrough.py` belong to an earlier visual overview and are not the source of this screen recording.
